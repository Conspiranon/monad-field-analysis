# Monad‑Field Analysis  
*A constitutive‑substrate framework for gravitational phenomena*

This repository contains analysis code, data products, and validation tests for the **Monad‑Field Framework** — a constitutive‑substrate model designed to reproduce gravitational observables without invoking particle dark matter.

## 📌 Included in this repository
- **NGC 1052‑DF2 velocity‑dispersion fits**  
  - Bounded, corrected, linear, and full model fits  
  - Sigma‑clipping and outlier‑rejection workflows  
  - Reproducible `.npz` data products

- **SPARC rotation‑curve analysis**  
  - Monad‑Field radial‑tension predictions  
  - Comparison with observed baryonic curves  
  - Residual diagnostics

- **LIGO post‑merger waveform fits**  
  - Constitutive‑substrate damping predictions  
  - Frequency‑domain tension‑gradient modeling

## 🧠 What is the Monad‑Field?
The Monad‑Field is a **continuous, constitutive substrate** whose internal tension gradients generate the phenomena normally attributed to gravity.  
Instead of curvature or particle dark matter, the framework uses:
- A scalar substrate density  
- A tension‑gradient operator  
- A constitutive relation linking tension to observable accelerations  

This repository contains the numerical experiments used to validate those predictions.
